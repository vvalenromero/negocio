## ✅ Flujo verificado en navegador real (CDP)
1. Saludo automático del agente (24/7) → chips de servicios.
2. Elegir servicio → elige día (5 días hábiles).
3. Elegir día → elige hora (9:00–20:00, bloquea ocupadas).
4. Elegir hora → pide nombre.
5. Nombre → resumen + confirmación con chip "Sí, confirmar".
6. Confirmar → aparece turno en agenda (KPI "turnos hoy" y monto $ actualizados).
- Los chips se re-renderizan bien y el flujo es robusto (se probaron clicks y envío por Enter).
- El título muestra el contador vivo de turnos.
